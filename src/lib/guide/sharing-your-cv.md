# Sharing your CV

There are two ways to put a document in front of someone, and the difference
between them is worth knowing before you send the first one.

## The public link

On a version, **Use as public resume** or **Use as public CV** makes that version
the one your public profile URL answers with. Anyone holding that URL can read
it — no sign-in, no token, nothing to expire. It's the link for a portfolio
site, an email signature, a profile elsewhere.

**If you set neither, that URL doesn't work.** With no public version, your
documents are reachable only through a private link. That is the switch: setting
a public version is what makes a document public, and unsetting it takes it back
again.

## Private links

**[Share Links](/profile/share)** creates a separate, unguessable link for one
recipient. Each one carries:

- a **label**, so you know later who it went to
- the **version** it shows
- **Resume (compact)** or **CV (full)**
- **HTML** to read in a browser, or **PDF** to download
- an optional **visit limit** — leave it blank for unlimited
- an optional **expiry date**
- **private notes**, which only you ever see

And each one counts its **views** and records when it was **last accessed**.

That's the reason to make one per recipient rather than reusing a link: a view
count only tells you something when you know whose it is. Delete a link and it
stops working immediately.

## Which to use

Use the **public link** when you're publishing — you want it read, you don't care
by whom, and you'd rather it not break.

Use a **private link** when you're sending it to a person: a specific version for
a specific company, that you can expire, count, and revoke afterwards. It also
means a document tailored to one employer doesn't sit at a permanent address.

> Both serve documents from the same profile, so an edit shows up in every link
> already sent. That is usually what you want — a typo fixed everywhere — but
> it's worth remembering that a link you sent last month does not show what it
> showed last month. See [Resumes & CVs](/guide/resumes-and-cvs) for how versions
> decide what a document prints.
